NAOW OR NEVER — site vitrine
=============================

Fichiers :
- index.html : structure du site
- style.css  : design responsive
- script.js  : menu mobile, animations et formulaire
- assets/logo-naow-or-never.png : logo avec fond retiré pour le web

AVANT LA MISE EN LIGNE :
1. Dans script.js, remplacez VOTRE-EMAIL@EXEMPLE.FR par votre adresse professionnelle.
2. Dans index.html, remplacez le lien Instagram par votre vrai profil.
3. Remplacez les blocs "VOS PHOTOS ICI" par vos photos.
4. Remplacez les témoignages d'exemple par vos vrais avis.
5. Vérifiez les mentions légales et politique de confidentialité avant publication.
